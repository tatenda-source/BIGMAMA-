# BIGMAMA$ User Guide

## 1. Reporting an Incident
- Navigate to the **Dashboard** or **Hotspot Map**.
- Click the **Report Incident** button.
- Follow the 2-step process:
  - **Step 1**: Provide a title and description of the activity.
  - **Step 2**: The platform captures your GPS location automatically. Upload photo/video evidence.
- Toggle **Anonymous Reporting** if you wish to hide your identity.

## 2. Using the Hotspot Map
- View verified (red) and unverified (yellow) reports.
- Click on markers to see case details and evidence.

## 3. Land Verification
- Enter a stand number or property ID.
- The tool cross-references with community-verified records to flag high-risk transactions.

## 4. Privacy & Performance
- Use **Low Data Mode** in Settings to disable heavy animations and blurs.
- Use **Emergency Wipe** to clear local session data instantly.
